# Avenora

A Next.js website with a section based homepage and a frontend stack focused on motion and presentation.

## Homepage

The homepage composes a hero, philosophy section, services section, process section, and a closing call to action. Each section is implemented as a separate component in `components/home/`.

## Technology

Next.js 16, React 19, TypeScript, Tailwind CSS 4, GSAP, Lenis, and SplitType. The project also includes Vercel Analytics and Speed Insights dependencies.

## Run locally

With Node.js and npm installed:

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

## Available commands

`npm run dev` starts the development server.

`npm run lint` runs ESLint.

`npm run build` creates a production build.

`npm start` serves the production build.

## Code guide

`app/page.tsx` composes the homepage sections.

`components/home/` contains the homepage components.
